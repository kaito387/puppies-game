## 1. 建模范围

- 用例图：玩家与系统的交互边界。

## 4. 序列图

### 4.1 游戏启动与离线结算

```mermaid
sequenceDiagram
  participant Browser
  participant App
  participant Store as Zustand Store
  participant Save as save.ts
  participant GameLoopEngine as gameLoop.ts

  Browser->>App: 加载页面
  App->>Store: 初始化 store
  Store->>Save: loadGame()
  Save-->>Store: GameState
  Store->>GameLoopEngine: applyOfflineProgress(state)
  GameLoopEngine-->>Store: 新状态、事件、模拟 tick 数
  Store->>Save: saveGame(离线结算后状态)
  Store-->>App: gameState/logs
  App-->>Browser: 渲染控制台
```

### 4.2 自动 tick

```mermaid
sequenceDiagram
  participant Timer
  participant App
  participant Store
  participant Engine as gameLoop.ts
  participant Save as save.ts

  Timer->>App: 每 200ms 触发
  App->>Store: tick()
  Store->>Engine: tick(gameState)
  Engine-->>Store: nextState + events
  Store-->>App: 更新资源、人口、日志
  alt 每 10 tick
    App->>Store: saveGame()
    Store->>Save: 写入 localStorage
  end
```

### 4.3 购买建筑

```mermaid
sequenceDiagram
  participant Player
  participant Panel as BuildingPanel
  participant Store
  participant Building as buildings.ts

  Player->>Panel: 点击购买
  Panel->>Store: canBuildBuilding(id)
  Store->>Building: 校验资源、前置、上限
  Building-->>Store: true/false
  alt 可购买
    Panel->>Store: buildBuilding(id)
    Store->>Building: 扣资源并增加建筑数量
    Building-->>Store: nextState
    Store-->>Panel: 刷新可购买列表
  else 不可购买
    Panel-->>Player: 按钮禁用或显示成本不足
  end
```

### 4.4 研究科技

```mermaid
sequenceDiagram
  participant Player
  participant Panel as TechnologyPanel
  participant Store
  participant Tech as technologies.ts

  Player->>Panel: 点击研究
  Panel->>Store: canResearchTechnology(id)
  Store->>Tech: 检查资源和前置
  Tech-->>Store: true/false
  alt 可研究
    Panel->>Store: researchTechnology(id)
    Store->>Tech: 扣资源并记录科技 ID
    Tech-->>Store: nextState
  end
```

## 5. 状态图

### 5.1 游戏运行状态

```mermaid
stateDiagram-v2
  [*] --> Loading
  Loading --> OfflineSettlement: 存在 lastTickTime
  Loading --> Running: 无需结算
  OfflineSettlement --> Running
  Running --> AutoSaving: 达到自动保存间隔
  AutoSaving --> Running
  Running --> ManualSaving: 玩家手动保存
  ManualSaving --> Running
  Running --> Resetting: 玩家重置
  Resetting --> Running
```

### 5.2 建筑可用状态

```mermaid
stateDiagram-v2
  [*] --> Hidden
  Hidden --> VisibleLocked: 达到显示条件但不可购买
  VisibleLocked --> Affordable: 资源足够且满足前置
  Affordable --> Owned: 购买
  Owned --> VisibleLocked: 资源不足
  Owned --> Affordable: 资源再次足够
```

### 5.3 狗狗状态

```mermaid
stateDiagram-v2
  [*] --> Idle
  Idle --> Working: 分配岗位
  Working --> Idle: 取消岗位
  Working --> Starved: 食物不足且人口衰减
  Idle --> Starved: 食物不足且人口衰减
  Starved --> [*]
```

## 6. 活动图

### 6.1 主循环活动

```mermaid
flowchart TD
  A["触发 tick"] --> B["计算人口上限"]
```

## 8. 模型与实现对应关系

| 模型元素 | 实现位置 |

| 存档 | `src/engine/save.ts` |

| 面板 UI | `src/components/*.tsx` |
